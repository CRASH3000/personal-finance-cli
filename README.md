# Budget Tracker CLI

Учебный проект на TypeScript: консольное приложение для учёта бюджета.
Сейчас проект делает базовую проверку окружения: компилируется и запускается через Node.js.

## Команды для запуска проекта

- Сборка:
  ```bash
  npm run build
  ```
- Запуск:
  ```bash
  npm start
  ```
- Режим разработки (автопересборка):
  ```bash
  npm run dev
  ```
- Универсальная команда:
  ```bash
  npm run build && npm start
  ```
