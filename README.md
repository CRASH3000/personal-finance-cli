# Budget Tracker CLI

<img src="docs/does-mr-krabs-love-money-or-is-he-in-love-with-money.png" alt="Скрин" width="350">

Учебное консольное приложение для управления личными финансами. 

## Возможности

- Создание и удаление счетов
- Просмотр сводки по счету: баланс / доходы / расходы
- Добавление транзакций (доход/расход) с проверкой ввода
- Удаление транзакций с подтверждением
- Экспорт транзакций счета в `.csv`

## Как запустить локально (Windows / macOS / Linux)

### Требования
- **Node.js** 
- **npm** 

### Установка и запуск
```bash
npm install
```
```bash
npm run build
```
```bash
npm start
```

## Управление в приложении
- **Стрелки** - выбор пункта меню
- **Enter** - подтвердить выбор
- **Пустой Enter** в полях ввода - шаг назад (отмена текущего ввода)
- **Ctrl+C** - аварийный выход из приложения
